## 2. Phase 2 — mémoire & auto-amélioration

### 2.1 Schéma et API

`MemoryStore.init_schema()` crée 9 tables + index + `schema_meta` (version 1).
Clés étrangères activées, `ON DELETE CASCADE`, verrou `RLock` pour les vagues
parallèles. `redact()` masque clés API, tokens (`ghp_…`, `sk-…`, `AKIA…`),
mots de passe, en-têtes et blocs PEM **avant** insertion — y compris dans les
valeurs sérialisées en JSON.

| API | Effet |
| --- | --- |
| `record_mission(dict \| str, **kw)` | insert/upsert, retourne l'id |
| `record_squad(mid, name, wave)` | escouade rattachée |
| `record_result(mid, agent_id, …)` | durée, tokens, artefacts, preuves |
| `record_failure(mid, agent, profile, type, msg)` | échecs indexés par profil |
| `upsert_recette(project_type, pattern, steps, …)` | recette **par type de projet** |
| `get_recettes(project_type=None, min_success=0)` | tri par score décroissant |
| `log(actor, role, action, detail)` | log d'orchestration persistant |
| `stats()` | compteurs pour les rapports de preuve |

`configure(path)` / `get_store()` exposent le store par défaut utilisé par les
API module-level `record_mission()` et `get_recettes()`.

### 2.2 Auto-amélioration active

Seuil **2 échecs du même profil** → `AutoFix.check(profile)` :

1. signature SHA-256 des incidents (idempotence via `autofix_runs`) ;
2. `build_corrected_fiche()` : une règle corrective par `error_type`, protocoles
   universels, mention `human_merge_required: true` ;
3. branche `omnibrain/fix-<agent>` → écriture de la fiche → commit → push → PR ;
4. log `WARN` en base. **Aucune méthode `merge` n'existe** sur les backends.

`OMNIBRAIN_AUTOFIX_APPLY=1` est requis pour exécuter réellement `git`/`gh` ;
sinon `CommandBackend(dry_run=True)` trace les commandes. `RecordingBackend`
sert aux tests.

### 2.3 Optimisation GEPA

`PromptOptimizer.optimize(n)` : `evidence()` (échecs, réussites, recettes) →
`reflect()` (règles non couvertes + recette la mieux notée) → `score()` =
`0.7 × couverture + 0.3 × taux de réussite` → acceptation **uniquement sur gain**.
Chaque itération est écrite dans `prompt_iterations` **et** dans le JSONL, avec
`ts`, scores, `accepted`, `uncovered`, `rationale`, `reflection_backend`.
`OMNIBRAIN_LLM_CMD` permet de déléguer la réflexion sans changer le
déterminisme par défaut (hors ligne).

## 3. Phase 3 — orchestration robuste

### 3.1 Graphe d'état

`StateGraph.order()` = tri topologique déterministe ; un cycle lève `ValueError`.
Chaque nœud et chaque gate ajoute une entrée `GraphState.history`
`(step, kind, node, status)`. Les gates HITL exigent une approbation explicite :
sinon escalade `{node, approver: "Lassana", status: "AWAITING_HUMAN"}` et arrêt.
`run_pipeline()` relie mémoire, télémétrie, sandbox et rapport de mission.

### 3.2 E2B + fallback

`Sandbox.run_code()` tente `run_code`/`runCode` du SDK E2B si `E2B_API_KEY` est
présente ; SDK absent, clé absente, exception ou timeout → sous-processus local
isolé. `SandboxResult.fallback_reason` est toujours renseigné : aucune
intégration prétendue.

### 3.3 Runtime

`Runtime.submit/tick/start/stop` : scheduler borné, `RuntimeConfig(interval_s,
max_ticks, artifacts_dir)`. `ROLE_PERMISSIONS` + `IRREVERSIBLE` : une machine ne
peut jamais fusionner ; `store.log()` persiste chaque tick.

## 4. Phase 4 — qualité continue

- **Télémétrie** : `WaveTelemetry.summary()` → `export_json()` →
  `render_markdown()`. `from_memory()` reconstruit depuis la base.
- **Benchmarks** : 10 `BenchmarkTask` figés, `task_fingerprint()` SHA-256,
  `run_once()` mesure le routeur réel (`hit_rate`, latence, agents, tokens),
  `compute_gains()`compare à la 1re passe de même empreinte, historisation
  JSONL + table `benchmarks`. `--no-write` pour la CI.
- **Catalogue** : 103 `AgentSpec` → 115 agents. 3 ajouts utiles :
  `observability-telemetry` (engineering), `memory-sqlite` (data-ai),
  `risk-gate-keeper` (qa-testing, `risk=true`). Hygiène étendue : bannis
  génériques, longueur ≥ 3, pas de doublon interne, pas d'espace résiduel,
  3–12 mots-clés, non-régression des faux positifs. Un doublon v3
  (`cryptography`: `chiffrement` × 2) a été corrigé → `gestion de clés`.
